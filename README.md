# Gyuler Gancheva - Portfolio

## About the project

This is a personal portfolio website created as a web development project.

The page includes a short introduction, a list of skills and a Live Data section that retrieves real information from the GitHub API.

## Technologies

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub API

## Features

- Responsive design for desktop and mobile devices
- Flexbox layout
- GitHub API integration
- Dynamic display of GitHub profile data
- Error handling with try/catch
- Separate JavaScript functions for different tasks

## How to run the project

1. Clone the repository.
2. Open `index.html` in a browser.
3. Alternatively, use Live Server in Visual Studio Code.

The project is also available online through GitHub Pages.

## API

The project uses the public GitHub API to retrieve information about the GitHub profile.

The following data is displayed dynamically:

- GitHub username
- Number of public repositories
- Number of followers
- Link to the GitHub profile

While working on this project, I learned how to:

- Create a responsive webpage with HTML and CSS
- Use Flexbox for page layout
- Use JavaScript functions to organize code
- Use `fetch()` to retrieve data from a public API
- Work with asynchronous JavaScript using `async/await`
